# ISO 639-3

## Definition

ISO 639-3 is a standard that gives a unique three-letter code to every known human language. It aims to cover every documented individual [language](language.md), whether living, extinct, ancient, or constructed,<sup>1</sup> going well beyond the smaller ISO 639-1 two-letter set that most developers know from the web's `lang` attribute.

### Why it matters in design systems

When a language is not in the short two-letter list, teams sometimes conclude it "cannot be tagged" or force it into a near-neighbour's code. ISO 639-3 is the answer: it sorts identifiers into three scopes, individual languages, [macrolanguage](macrolanguage.md)s, and collections,<sup>2</sup> and it reaches languages the two-letter set never named. [SIL Global](../../design-terms/typography/sil.md) maintains it as the registration authority.<sup>3</sup> Use it as the stable identifier for language metadata, pickers, and font or content selection, and reach for it precisely when 639-1 runs out. A caution on level: a language code names a language, not a [script](../writing-systems-and-scripts/script.md) or a [locale](../../programming-terms/text-for-digital-products-and-the-web/locale.md), so "which code" is a different question from "which script do we render" or "which regional variant do we ship."

### Example

The code `cmn` identifies Mandarin Chinese and `eng` identifies English. Most of the world's languages have only a three-letter ISO 639-3 code and no two-letter ISO 639-1 form at all, which is exactly when 639-3 is the identifier to use.
