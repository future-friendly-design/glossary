# Alphasyllabary

## Definition

Alphasyllabary is a near-synonym for [abugida](abugida.md), a type of [script](script.md) where each consonant carries a built-in vowel that added marks change.<sup>1</sup> The two terms come from different scholars: Peter Daniels proposed "abugida", and William Bright proposed "alphasyllabary". Most references use them interchangeably, but their definitions are not identical. "Abugida" names the vowel built into each consonant, while "alphasyllabary" names writing the other vowels as attached marks ([matras](matra.md)), so the two labels do not cover exactly the same set of scripts.<sup>2</sup>

This glossary uses abugida as the main entry. See [abugida](abugida.md) for the full definition, the Devanagari example, and what it means for shaping and layout.
